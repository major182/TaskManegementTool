# 01-2 機能要件：タスク管理ツール（Trello風）

> [要件定義書（本体）](01_requirements.md) の「4. 機能要件」の詳細です。
> 各機能の使われ方は [01-1 ユースケース](01-1_use-cases.md#34-ユースケース一覧) を参照してください。

優先度：**Must**＝バージョン1で作る／**Should**＝次に追加したい／**Could**＝余裕があれば追加する

### 4.1 アカウント

> v0.12 で追加。データはサーバーに保存するため、誰のデータかを見分ける仕組みとしてログインを作ります。
> パスワード再設定・退会・メールアドレスの登録は作りません（メール送信の仕組みが必要になり、学習用の課題としては大きすぎるため）。


| ID   | 機能        | 内容                                                                   | 優先度  |
| ---- | --------- | -------------------------------------------------------------------- | ---- |
| F-05 | 新規登録      | ユーザーID とパスワードを入力してアカウントを作る。すでに使われている ID は登録できない。登録するとそのままログインした状態になる | Must |
| F-06 | ログイン      | ユーザーID とパスワードを入力してログインする。どちらかが違うときは「ユーザーID またはパスワードが違います」と表示する       | Must |
| F-07 | ログアウト     | サイドバーの「ログアウト」でログイン前の状態に戻る                                            | Must |
| F-08 | ログイン状態の保持 | ログインすると、ブラウザを閉じて開き直しても最大30日間はログインしたままになる（**サーバーの再起動・スリープ時は解除され、再ログインが必要**）。未ログインでアプリを開いたときはログイン画面を表示する | Must |




### 4.2 データの保存


| ID   | 機能         | 内容                                                            | 優先度  |
| ---- | ---------- | ------------------------------------------------------------- | ---- |
| F-01 | 自動保存       | ボード・リスト・カードを作成・編集・削除・移動したとき、その都度サーバー（データベース）に自動で保存する。保存ボタンはない | Must |
| F-02 | 保存データの読み込み | アプリを開いたとき・再読み込みしたときに、サーバーからログイン中の利用者のデータを取得して表示する             | Must |
| F-04 | 通信エラーの表示   | サーバーとの通信に失敗したときは、「保存できませんでした」などのメッセージを表示し、やり直せるようにする          | Must |




### 4.3 ボード


| ID   | 機能      | 内容                                                                   | 優先度  |
| ---- | ------- | -------------------------------------------------------------------- | ---- |
| F-11 | ボード一覧   | サイドバーにボードを一覧で表示する                                                    | Must |
| F-12 | ボード作成   | ボード名を入力して作成する                                                        | Must |
| F-13 | ボード編集   | ボード名をその場で変更する                                                        | Must |
| F-14 | ボード削除   | ボードを、中のリスト・カードごとゴミ箱へ移動する                                             | Must |
| F-15 | ボード切り替え | サイドバーでボードを選ぶと、同じ画面のままリストとカードの表示が切り替わる。最後に開いていたボードを覚えておき、次に開いたときに表示する | Must |
| F-16 | ボード並び替え | サイドバーでボードをドラッグ＆ドロップして順番を変える。並び替えた順番は保存される | Must |




### 4.4 リスト


| ID   | 機能      | 内容                             | 優先度  |
| ---- | ------- | ------------------------------ | ---- |
| F-21 | リスト作成   | ボード内にリストを追加する                  | Must |
| F-22 | リスト編集   | リスト名を押して、その場で変更する              | Must |
| F-23 | リスト削除   | リストを、中のカードごとゴミ箱へ移動する           | Must |
| F-24 | リスト並び替え | ドラッグ＆ドロップで順番を変える。並び替えた順番は保存される | Must |




### 4.5 カード


| ID   | 機能     | 内容                                                           | 優先度   |
| ---- | ------ | ------------------------------------------------------------ | ----- |
| F-31 | カード作成  | タイトルを入力して追加する                                                | Must  |
| F-32 | カード編集  | カードを押すと、その場でタイトル・説明文の入力欄に変わり、編集できる（別の画面やポップアップは開かない）         | Must  |
| F-33 | カード削除  | カードをゴミ箱へ移動する                                                 | Must  |
| F-34 | カード移動  | ドラッグ＆ドロップで同じリスト内・別のリストへ移動する。移動後の位置は保存される                     | Must  |
| F-38 | 完了チェック | カードのチェックボックスで、完了・未完了を切り替える。完了したカードは取り消し線と薄い色で表示し、一目でわかるようにする | Must  |
| F-35 | 期限日    | カードに期限日を設定・変更・削除する（空欄でもよい）。期限日を過ぎた未完了のカードは、日付を色で目立たせる          | Must  |
| F-36 | ラベル    | 色付きラベルを付ける                                                   | Could |
| F-37 | 検索     | カードのタイトルで検索する                                                | Could |




### 4.6 ゴミ箱


| ID   | 機能       | 内容                                                                            | 優先度  |
| ---- | -------- | ----------------------------------------------------------------------------- | ---- |
| F-41 | ゴミ箱一覧    | サイドバーの「ゴミ箱」を押すと、表示エリアに削除したボード・リスト・カードの一覧（種類・名前・元の場所・削除日時）を表示する。サイドバーには件数を表示する | Must |
| F-42 | 元に戻す     | ゴミ箱のデータを元の場所に戻す（リストは一番右、カードは一番下に入る）                                           | Must |
| F-43 | 完全に削除    | 確認ダイアログのあと、ゴミ箱のデータを1件ずつ完全に削除する。元に戻せない                                         | Must |
| F-44 | ゴミ箱を空にする | 確認ダイアログのあと、ゴミ箱のデータをすべて完全に削除する。元に戻せない                                          | Must |

| ---- | ------------- | ---------------------------- | ----- |
